How we work

How a game gets built

From idea to Play Store, in the open.

  1. Discovery

    You describe the game in plain words — what the player does, and what makes it fun. We ask questions, play reference games, and tell you honestly if it is a good fit.

  2. Design & fixed scope

    Core loop, mechanics, level structure, and monetization, agreed in writing — with a fixed price, what is included, and what is not. No surprises later.

  3. Playable prototype

    The core loop becomes playable early, so you feel the fun before the full build. If the loop does not work, we fix the design — not the code.

  4. Build in tested steps

    We build in small steps, testing as we go. You see working builds throughout — not a big reveal at the end.

  5. Playtest on real phones

    Every build is verified on a real device before we call it done. You test it on your phone too, before handover.

  6. Release & handover

    Play Store release, listing drafts, and the complete source code with build documentation. The game is yours.

About the studio

Questions

Before you ask.

How much does a game cost?

Puzzle game builds typically run $3,000–$5,000 depending on scope. Branded games are scoped per project. You get a fixed price in writing, with what is included and what is not, before any work starts.

How long does a game take?

It depends on scope — mechanics, level count, and polish. The timeline is set in the written scope before work starts, and you see working builds throughout, so progress is never a mystery.

Do you build for iPhone too?

We build for Android and Google Play. If you need iOS as well, tell us in your inquiry and we will give you an honest answer about the best route.

Who owns the game when it is done?

You do. The game, the store listing drafts, and the full source code with build documentation are handed over to you on final payment.

Can you guarantee downloads or earnings?

No — and neither can anyone honest. Downloads and earnings depend on the game, its listing, and its marketing. What we guarantee is the build itself: working, tested, and yours.

Have a game in mind?

Send the idea — even half-formed. We will tell you honestly what it would take, even if the answer is not us.
