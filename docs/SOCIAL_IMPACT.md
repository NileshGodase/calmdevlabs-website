## Rules for this content (do not weaken)

1. **Profits, not revenue.** Every mention must say *profits*. Grep for `5%` before
   every release and confirm.
2. **Commitment, not track record.** No contributions have been made yet (as of
   2026-10-11). Present it as an ongoing commitment. The "Impact updates" block
   honestly states: "No contributions published yet."
3. **No invented specifics.** Never add donations, beneficiary numbers, partner NGOs,
   sponsorships, scholarships, certificates, counters, or testimonials without
   verified evidence.
4. **Not a charity.** CalmDevLabs is a for-profit software studio. The site states
   this explicitly. Never imply registered-charity/nonprofit status.
5. **No fundraising.** This is not a donation checkout; we do not solicit donations.
6. **Future reporting** must match actual accounting and contribution records.
